## My meeting transcripts

My Amberscript meeting/note transcripts are stored as markdown files in
`~/Documents/AGI` (Windows: `%USERPROFILE%\Documents\AGI`), named
`YYYY-MM-DD-title.md` with YAML front matter.

Whenever a question could relate to my meetings, calls, interviews, or notes,
search that folder by filename and content and read the relevant transcripts
before answering. Treat them as my personal knowledge base.

To pull in new transcripts on demand, use the `amber-notes` MCP tools to list
transcripts and save any missing ones into that folder using the same naming
convention (never overwrite existing files).
